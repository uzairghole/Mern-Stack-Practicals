## 📌 About The Repository

This repository documents hands-on practical exercises developed as part of the **MERN Stack curriculum**. It systematically transitions from core JavaScript logic and ES6+ functional concepts to building modern, component-driven web interfaces using **React.js** bundled with **Vite**.

## 💻 Environment & Setup Guide

### 1. Standalone JavaScript Scripts (Practical 1 & 2)

Run any raw JavaScript script via **Node.js** in your terminal:

```bash
# Execute Practical 1 scripts
node Practical1/add.js
node Practical1/practical1_3.js

# Execute Practical 2 scripts
node Practical2/array_method.js
node Practical2/product.js

```

---

### 2. React Applications (Practical 3, 4 & 4_2)

Each React directory uses **Vite** as its build tool and development server.

```bash
# 1. Navigate into any React application directory
cd Practical3/reactproject
# OR
cd Practical4
# OR
cd Practical4_2

# 2. Install project dependencies
npm install

# 3. Start the Vite local development server
npm run dev

```

> **Default Local Server URL:** `http://localhost:5173`
